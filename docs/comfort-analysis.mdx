Comfort Analysis は、今のポーズで関節や筋にかかる負荷を計算し、負担の小さい姿勢への経路を示すウィンドウです。メニューの **Tools > IKFKController > Comfort Analysis** で開きます。

## 計算すること

- 身長、体重、性別などの体格を使って、関節ごとの負荷を計算します。
- 関節ごとの負荷率を求め、最も大きい値を、そのポーズの最大の負荷率として示します。
- 体を支える力が必要と判定されたポーズは、負荷率によらず「耐え難い」とします。

## 負荷率の段階

| 最大の負荷率 | 段階 |
| --- | --- |
| 2% 未満 | 極めて快適 |
| 5% 未満 | 快適 |
| 15% 未満 | 特に問題なし |
| 30% 未満 | まあまあ大丈夫 |
| 50% 未満 | まだ耐えられる |
| 100% 未満 | ギリギリ耐えられる |
| 100% 以上、または支えが必要 | 耐え難い |

段階の境界は、仮に決めた値です（Assumed）。出典の目安は、「約 15% は長時間保てる」「約 50% は約 2 分」という Ergoweb の記載です。目安をそのまま使い、境界の値は仮定として扱っています。

## 体位の名前

立位や座位などの体位の名前は、表示のラベルとして使うだけです。判定には使いません。

## 前提

- 体が直立していることを前提にします。傾いたポーズは、解析の対象になりません。
- 体格は、Comfort Analysis のウィンドウで決めた値を使います。Pose Controller のアシストとは、体格を共有していません。
