## IK と FK の切り替え

手と足は、それぞれ IK か FK を選べます。切り替えても、今のポーズは保たれます。切り替えは、元に戻す（Undo）1 回で戻せます。

- **IK**: 手や足の先の箱を動かして、体の形を決めます。
- **FK**: 関節の角度を直接使います。

詳細の中にある **IK Weight** は IK の効き具合です。0 にすると、IK にする前の FK の姿勢に戻ります。

## ポールの向き

ポールは、IK にした腕や脚の、肘と膝の向きを決めます。腕が真っすぐなときは肘が後ろ、脚が真っすぐなときは膝が前を向きます。向きは体の向きから決めます。

## ミラー

- **Mirror**: 体全体を左右反転します。
- **L → R**: 左半身の姿勢を、右半身へ写します。
- **R → L**: 右半身の姿勢を、左半身へ写します。

ミラーは、関節の角度ではなく、Unity の Humanoid の筋（マッスル）の値で行います。ボーンの向きの違いに影響されにくくするためです。

## 既知の制約

- ミラーと、ポーズの適用（Apply Pose）では、Undo で指などの骨が元に戻らない場合があります。
