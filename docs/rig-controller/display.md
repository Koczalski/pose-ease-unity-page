## 見た目

- **Style Preset**: 見た目の組み合わせを選びます。
- **Show**: 表示する種類を選びます。
- **ラベル**: 既定では、ホバーした関節と選んだ関節にだけ名前の札が出ます。ラベルを常時表示にすると、札は体の外側へ寄せて並べ、重なる札は縦にずらします。

## View Preset

View Preset は、シーンビューの背景と光を切り替えて、Rig Controller の色を見やすくします。シーンのファイルは書き換えません。

- **シーンのまま（既定）**: シーンビューの設定をそのまま使います。
- **ニュートラル**: Skybox、霧、画像効果を切ります。シーンの光とグリッドは残します。
- **フラット**: ニュートラルに加えて、シーンの光を止め、グリッドも切ります。

「シーンのまま」を選ぶか、**元に戻す** を押すと、もとの設定に戻ります。

## 縁取り

Rig Controller の線は、暗い縁の外側に明るい縁が付いています。黒い服にも白い服にも見えやすくするためです。
