Rig Controller は、アバターの関節をシーン上の制御点で動かす仕組みです。Pose Controller ウィンドウで選んだアバターに表示されます。

![Rig Controller の形の模式図。FK の輪、IK の箱、ポールの菱形、Root の輪を並べている](/img/controllers.svg)

## 種類と見た目

| 種類 | 形 | 役割 | 操作 |
| --- | --- | --- | --- |
| FK | 骨の軸まわりの細い輪 | 関節の回転を直接決める | 選んでから、回転ギズモで回す |
| IK | 12 辺の箱 | 手や足の先の位置を決める | 直接ドラッグ |
| ポール | 菱形と、肘・膝への実線 | IK のとき、肘や膝の向きを決める | 直接ドラッグ |
| Root | 塗りのない輪と四方の矢印 | 体全体の位置を決める | 直接ドラッグ |

色は、左が青、右が赤、中央が黄色です。

## 操作

- **クリック**: 選びます。何もない所をクリックすると、選択が外れます。組み込んだ Rig Controller は、選択が外れると消えます。選び直せば出ます。
- **直接ドラッグ**: IK、ポール、Root は、カメラに正対する面の上で直接ドラッグできます。
- **Shift を押しながらドラッグ**: 動きを、縦と横のうち大きい方の向きに固定します。
- **FK の回転**: FK の輪を選んでから、回転ギズモで回します。ギズモの座標系は、Unity の Pivot Rotation（Local か Global）の設定に従います。
- **元に戻す**: 1 回のドラッグが、元に戻す（Undo）1 回になります。Ctrl+Z で戻せます。
