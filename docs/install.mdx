title: インストール
description: 開発中の版を Unity プロジェクトに入れる方法と、確かめ方。
---

## 必要なもの

- Unity 2022.3.22f1
- Burst パッケージ（解析の計算に使います）
- VRChat SDK（アバターをアップロードする場合のみ。組み込みは SDK が無くても動きます）

## 入れ方

配布の形（パッケージ、ZIP など）はまだ決まっていません。〔要確認〕

開発中の版は、拡張のフォルダ `Assets/IKFKController` を、Unity プロジェクトの `Assets` の下に置いて使います。

## 確かめ方

Unity のメニューに **Tools > IKFKController > Pose Controller** が出れば、入っています。
