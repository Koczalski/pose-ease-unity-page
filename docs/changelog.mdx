## 開発中（未リリース）

版番号はまだ決めていません。

- **Rig Controller の刷新**: 見た目の調整、IK・ポール・Root の直接ドラッグ、Shift で向きを固定、肩の FK、手足ごとの IK/FK の切り替え、ミラー。
- **表示**: View Preset（シーンのまま、ニュートラル、フラット）と、縁取りの二色化。
- **アバターへの組み込み**: Root の下に Rig Controller を 1 つ追加する機能。
- **アシスト（解析）**: 関節の負荷の印と数値、推定した支え、接地のずれ、負荷の大きい関節の一覧。自然に寄せる（経路・ゴースト・適用）と、選んだ手足の筋の活性。
- **言葉でポーズ（LLM）**: 言葉の指示から 3 案を作り、言葉の条件を保って楽な姿勢へ寄せてから、ゴーストで見比べて適用（Undo 1 回）。今のポーズの説明。通信は 127.0.0.1 の llama-server だけ。
