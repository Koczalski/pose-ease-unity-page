アシストは、Pose Controller のウィンドウで、今のポーズの負荷を見ながらポーズを作るための機能です。Comfort Analysis と同じ計算を使います。

## 状態

| 機能 | 状態 |
| --- | --- |
| 関節ごとの負荷の印と数値 | 使えます |
| 推定した支えと、接地のずれ | 使えます |
| 負荷の大きい関節の一覧（上位 5 つ） | 使えます |
| 負担の小さい姿勢へ寄せるスライダー（自然に寄せる） | 使えます |
| 選んだ手足の筋の活性 | 使えます |
| ドラッグ中も追従して表示すること | <span class="status-planned">予定（計測と確認の後）</span> |

## 使い方

1. Pose Controller ウィンドウの **アシスト（解析）** の節で、「有効」にします。既定はオフです。
2. 体格（身長、体重、性別）を入れます。既定は 1.60 m、50 kg、女性です。この体格は、Comfort Analysis とは別に持ちます。
3. ポーズを動かします。評価は、ドラッグを離したときに 1 回だけ行います。元に戻す、やり直す（Undo、Redo）の後も評価します。
4. 腕か脚のコントローラーをシーンで選ぶと、**選んだ手足の筋** に、その手足の筋の活性（上位 5 つ）が出ます。
5. **自然に寄せる** の「楽な姿勢を探す」を押すと、今のポーズから負担の小さい姿勢への経路を作り、半透明のゴーストを出します。アバターはまだ動きません。
6. 「寄せる量」のスライダーで、ゴーストを動かして確かめます。0 が今のポーズ、1 が経路の最後です。そのときの負荷率も出ます。
7. 「適用」でアバターに当てます。元に戻す（Undo）1 回で戻ります。IK だった手足は IK のままです。「破棄」は経路とゴーストを消すだけです。

## 表示の意味

- **関節の印**: 負荷率を、白からマゼンタの色で示します。負荷率 0〜50% の範囲で色が変わります。負荷の大きい関節には数値を付けます。
- **推定した支え**: 床や物の面が無いところに座るなど、体を支える面が無いときに、その面を推定して示します。推定した支えは、結果とは別の欄に書きます。
- **接地のずれ**: 解析が体を床に合わせるために動かした上下の量です。1 cm を超えると注記します。
- **ボーンの再現の誤差**: 解析の体のモデルと、Rig Controller の骨の位置とのずれです。3 cm を超えると、参考値として扱います。
- **選んだ手足の筋**: 関節の負荷を、標準の筋骨格モデルの筋に配分した活性です。腕は OpenSim Arm26（肩と肘の屈曲・伸展、6 筋）、脚は Rajagopal 2016 です。計算は Comfort Analysis の筋レベルの欄と同じです。
- **自然に寄せる**: 経路は Comfort Analysis と同じ方法で作ります。ただしアシストでは、ポーズ集の近い姿勢（体位の典型）と、LLM の提案は使いません。

## 注意

- 評価はドラッグを離したときだけです。ドラッグしている間、数値は変わりません。
- 数値は、体格と段階の境界という仮定に依存します。医療や労働の判断には使わないでください。
- 体が直立していることを前提にします。ルートが大きく傾いているときは、解析を行わず、理由を表示します。
- ポーズを動かすと、作った経路とゴーストは消えます。もう一度「楽な姿勢を探す」を押してください。
- 適用のとき、IK と FK の途中の重みにしていた手足は FK になります。
- 解析は体を上下させて接地させます（「接地のための上下」）。ゴーストと適用後の体の高さは、今のアバターとその分ずれます。
