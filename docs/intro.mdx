Unity エディタの中で、VRChat 向けの Humanoid アバターのポーズを作る拡張です。ポーズは Rig Controller を直接ドラッグして作ります。できあがったポーズが体にどれくらい負担をかけるかは、数値で確かめられます。

</Hero>

## 対応環境

- Unity 2022.3.22f1（Built-in Render Pipeline）
- Humanoid のアバター（Animator と Avatar が設定されているもの）
- ほかの Unity のバージョンや Render Pipeline では確かめていません。

## 読み方

はじめて使う人は、「インストール」「クイックスタート」の順に読んでください。数値の出典と仮定は、それぞれのページと [出典とライセンス](./credits) に書いてあります。
