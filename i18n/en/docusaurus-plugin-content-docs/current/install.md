## Requirements

- Unity 2022.3.22f1
- The Burst package (used for the analysis calculations)
- The VRChat SDK, only if you upload avatars. Installing on an avatar works without it.

## How to install

The distribution format (package, ZIP, and so on) is not decided yet. 〔要確認〕

For the development version, place the `Assets/IKFKController` folder under `Assets` in your Unity project.

## How to check

If **Tools > IKFKController > Pose Controller** appears in the Unity menu, the install works.
